MobiKOR

Вебсайт сервісного центру та магазину оригінальних гаджетів у Калинівці (Вінницька обл.). Навчальний проєкт з дисципліни «Технології веб розробки та дизайну», НУ «Львівська політехніка».

🔗 Демо: https://fascinating-arithmetic-9e9e3c.netlify.app 

Можливості
Hero-секція з фоновим відео та трьома кнопками дій
Світла й темна теми (перемикач, вибір зберігається в браузері)
Адаптивна верстка: мобільна, планшетна та десктопна версії, гамбургер-меню
Фотокарусель «Про нас» і карусель популярних товарів
Блоки «Як ми працюємо», калькулятор послуг і трекер квитанцій
Форма зворотного зв'язку з перевіркою номера телефону (+380…)
Сторінки: головна, магазин, ремонт, особистий кабінет
Технології

HTML5 · Tailwind CSS (CDN) · CSS-змінні для тем · JavaScript (без фреймворків) · Bootstrap Icons (лише шрифт іконок)

Запуск

Збірка не потрібна. Відкрийте index.html у браузері або запустіть через розширення Live Server у VS Code. Для завантаження Tailwind, іконок і карти потрібен інтернет.

Публікація

Netlify → сайт → Deploys → перетягнути папку проєкту в зону Drag and drop.

Примітки
Товари, ціни, номери квитанцій і відгуки на сторінках — демонстраційні, не реальні дані.
Tailwind підключено через CDN лише для навчальних цілей; для production його підключають через збірку.
